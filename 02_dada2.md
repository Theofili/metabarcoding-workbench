# 02 DADA2 Processing

In this demo we will be using dada2 for creating a ASV FASTA table.


More specifically this step performs:
1. Quality filtering
2. Error Learning
3. DADA2 denoising
4. Paired-read merging
5. Chimera removal
6. ASV FASTA export

Run:
```powershell
Rscript scripts\02_dada2.R
```

**This script might take a while to finish.**
